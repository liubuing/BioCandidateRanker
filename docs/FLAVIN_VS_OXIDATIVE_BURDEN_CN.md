# 试了 FAD：结论是它不该当把手，O₂/H₂O₂ 才该

日期：2026-10-12。起因是「FAD 应该去试试」。我去试了，结论与预期相反，记录如下。

## 一、试的结果：黄素在氧化酶里是催化剂，不是底物

酵母模型里 POX1（`r_0120`）的化学式是：

```
decanoyl-CoA + O2  →  H2O2 + trans-dec-2-enoyl-CoA
```

**没有黄素项**。起初我把这当成模型缺陷，但查完全部同族后确认这是**系统性且化学上正确的写法**：

- 模型里 **5 个以上酰基-CoA 氧化酶**（`r_0120`–`r_0125`）全部这样写
- 这些酶确实是**黄素依赖**的（FAD 作为辅基），但 **FAD 在反应内部循环再生，净反应不含黄素**
- 对氧化酶而言电子最终交给 **O₂**，产物是 **H₂O₂**；对脱氢酶（如大肠的 `ACOAD1fr`）电子交给呼吸链，模型才显式写出 FAD→FADH₂

**所以"测 FAD 周转"对氧化酶没有意义**——无论酶工作多快，净 FAD 消耗都是零。这也解释了我之前测到的"酵母基线下黄素周转≈0"：那不是模型缺陷，是化学事实。

**推论**：酵母王浆酸路线的降解侧不能看 FAD，要看 **O₂ 与 H₂O₂**。两者都是模型里真实存在的代谢物（H₂O₂ 参与 20 个反应、O₂ 参与 22 个）。

## 二、实现：氧化负担会计

新增 `fba_context.oxidative_burden`（按模型声明 `OXIDANT_METABOLITES`），按**方向分别报告**总量与主要反应——因为细胞既摄取氧、内部也消耗氧，且生成的过氧化物必须由过氧化物还原酶/过氧化氢酶清除，只有分方向的总量有工程意义。

锚点场景（路线 A、POX1 开放、生物量下限 10%、葡萄糖 1.0/氧 1000）：

| 氧化负担 | 总量 (mmol gDW⁻¹ h⁻¹) | 主要来源 |
|---|---:|---|
| **O₂ 消耗** | **1.0957** | `r_0120` POX1 **0.274**、**`CAND_T2DEC_OMEGA_HYDROXYLASE_P` CYP52M1 0.274**、`r_0125` 0.274 |
| **H₂O₂ 生成** | **0.8217** | `r_0120` POX1 **0.274**、`r_0125` 0.274、`r_0123` 0.274 |

### 两个可直接用于工程判断的读数

**① 路线的两个耗氧步骤都是化学计量明确的，各 1 单位/产物**
- P450 ω-羟化酶（CYP52M1）：每产物 1 O₂ ——与目标通量完全相等（0.2740 vs 容量 0.274011），已在测试里钉住
- POX1 降解入口：每产物 1 O₂，同时产生 1 H₂O₂

**② H₂O₂ 生成量（0.8217）是 POX1 贡献（0.274）的 3 倍**
差额来自其他链长的酰基-CoA 氧化酶（LP 为平衡氧化还原会并行运行它们）。也就是说：**产物路线只贡献了三分之一的过氧化物负担，另外三分之二来自维持性氧化**。这条对"要不要工程化过氧化物清除能力"是直接相关的——单看产物路线会低估。

## 三、与之前结论的关系（更正与保留）

| 之前的说法 | 现在的状态 |
|---|---|
| "加 FAD 就能定量 POX1 入口" | **错，已更正**——FAD 对氧化酶是催化剂 |
| "酵母基线下黄素周转≈0" | 对，但**原因是化学而非缺陷** |
| "大肠里 FAD 是有效把手（主力 ACOAD1fr）" | **保留**——脱氢酶确实显式带 FAD，净反应含黄素 |
| 降解侧改读 `r_0120` 通量 | **保留并扩展**——现在同时给出该步的 O₂ 消耗与 H₂O₂ 生成 |

## 四、过程中修掉的一个真实缺陷

给三个模型加 `oxidant_metabolites` 声明时，我的两次字符串替换都落在了 iML1515 条目上，造成**重复键**（Python 取后者，行为侥幸正确）；删除重复后 **iJO1366 反而漏了这个键**，导致该模型的氧化负担报告静默消失。

已修，并加了两条守卫测试：
- `test_every_model_declares_oxidant_handles`——任一模型缺声明即失败
- `test_oxidant_ids_exist_in_their_model`——声明的 ID 必须在模型里真实存在

## 五、边界

- O₂/H₂O₂ 是**模型通量**，不是实测的溶氧或胞内过氧化物水平
- 过氧化物对细胞的真实毒性取决于清除酶容量（过氧化物还原酶、过氧化氢酶），模型对此只有通量、没有速率常数
- 因此这些数字用于**相对比较与瓶颈定位**，不能当作"细胞能否承受"的判据
