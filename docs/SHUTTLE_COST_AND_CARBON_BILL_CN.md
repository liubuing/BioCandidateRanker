# 过氧化物酶体穿梭的代价与碳/氧供给账单

日期：2026-10-17。模块：`src/biocandidate/royal_jelly_acid.py`。运行入口：

```bash
python -m biocandidate.royal_jelly_acid --shuttle-cost-scan
python -m biocandidate.royal_jelly_acid --supply-requirement
```

本文回答前一轮分析留下的两个"然后呢"：

1. 自由穿梭（idealized shuttle）显示 IDP3 不是产能瓶颈——那**定价之后**呢？
   一个真实的转运蛋白要花 ATP、有速率上限，花到什么价格就不值得建了？
2. 容量受碳供给限制——那**拿到一个目标滴度**到底需要多少葡萄糖、多少氧气？
   通气在哪个点开始"值回票价"？

两个问题的答案都来自 LP 最优解，而不是网格扫描：网格的分辨率会伪装成答案。

---

## 一、有价穿梭（shuttle_cost_scan）

### 做法

在原自由交换反应的基础上增加两个维度：

- **ATP 价格**：每把 1 个 NADPH 送进过氧化物酶体，在**细胞质侧**水解
  `atp_cost` 个 ATP（ABC 转运蛋白模式：ATP + H₂O → ADP + Pi，四个代谢物
  全在细胞质，因为该模型没有过氧化物酶体磷酸物——这本身就是一个建模事实）。
- **速率上限**：反应上限 `capacity`，表示有限量的转运蛋白。

有价反应不可逆（花 ATP 把还原能送出去没有机制），反应 ID 编码价格
（如 `SHUTTLE_CYTOSOL_TO_PEROXISOME_ATP_DRIVEN_0P5`），不同价格互不覆盖。

### 结果（路线 A，默认培养基，生物量下限 10%）

| 情形 | 目标容量 (mmol/gDW/h) | 说明 |
|---|---|---|
| 无穿梭（基准） | 0.274011 | IDP3 独立供给 |
| 自由穿梭（0 ATP） | 0.274011213 | 受益 **+5×10⁻¹⁰**，本质为零 |
| 任何正价格（0.001 起） | 0.274011205 | **LP 完全弃用穿梭**，全部回落 IDP3 |
| 限速 0.02（仍远低于需求） | 0.274011213 | IDP3 补足差额，容量不变 |

三个判定字段把结论说死：

- `relief_is_negligible: true` —— 免费的穿梭也买不到东西（受益 ≤ 1%）；
- `min_atp_cost_with_unused_shuttle: 0.001` —— 第一个正价格上细胞就"罢购"；
- `capacity_insensitive_to_price / _to_cap: true` —— 价格与速率在测试范围内
  都不改变容量。

### 解读（这是本次的真正产出）

**王浆酸路线根本不被过氧化物酶体 NADPH 池门控。** IDP3 与假想穿梭是同一个
辅因子的两个来源，二者相加只有"总和"有意义：穿梭慢了 IDP3 补，穿梭贵了
细胞不用。因此：

- "给酵母加一个过氧化物酶体 NADPH 转运蛋白"这个改造方向，在**这个模型、
  这条路线、这个产能水平**上没有可兑现的收益——不是收益太小，是瓶颈不在这；
- 该结论**推翻了上一轮**"自由穿梭可缓解 IDP3 瓶颈"的表述中隐含的期待：
  缓解是名义上的（容量没动）；
- 若未来某一配置下 `relief_is_negligible` 变为 false，本扫描给出的
  `min_atp_cost_with_unused_shuttle` 才是转运蛋白必须打碎的预算线。

工程含义：改进应转向**碳供给与底物毒性**（见下）或酶表达水平（GEM 之外），
而不是辅因子区室化。

## 二、碳/氧供给账单（supply_requirement）

### 做法（三个 LP 组成的阶梯，不是网格）

把目标滴度换算成必需比通量
`需求 = 滴度 / (186.25 × 生物量 gDW/L × 小时)`，然后：

1. **最小葡萄糖**：氧放开（上限 1000），葡萄糖交换设为目标、封顶为 0、
   **最大化交换通量**（即最小化摄取——摄取是负通量）；
2. **钉住**最小葡萄糖（上下界同时钉——只钉下界会允许"少摄取"，悄悄放松
   最优），**最小氧气**同理求出；两个解都做副产物最小化的第三步 LP，
   因为最优是一张"面"，求解器任选一点的副产物通量是噪声不是化学；
3. 在每个通气上限下重解最小葡萄糖，与自由氧气的账单相比得
   `carbon_penalty_vs_free_oxygen`——**上限贵出 1% 以上才算"通气受限"**。

生物量下限统一取**参考培养基**（模型默认 1.0 葡萄糖）最大生长的 10%
（0.008953/h）。若按碳上限 1000 的培养基取下限，生长会高达 49/h，
推出的碳需求比产物还多——这是第一批实现里真实发生过并已修掉的错误。

### 生理化交换集（先修掉一个会污染所有红氧答案的假象）

模型自带约 270 个边界反应，包含大量工程化学。放开时 LP 会用**甲醇、
乙基丙酮酸**等酵母不会分泌的物种倾倒电子，得出"最低需氧 = 0"的假象。
现以 `PHYSIOLOGICAL_EXCHANGES`（26 个：碳/氮/磷/硫/金属 + 乙醇、乙酸、
甘油、丙酮酸、琥珀酸 + 候选路线需求反应）封闭其余 250 个；
**封闭后参考生长一字不变**（1e-12 内），并有测试
`test_restricting_the_exchange_set_removes_nothing_the_model_needs` 钉住。

### 结果（生物量 20 gDW/L，10 小时）

| 目标滴度 | 需求通量 | 最小葡萄糖摄取 | **平均账单** (g 葡萄糖/g 产物) | **边际账单** |
|---|---|---|---|---|
| 298.6 mg/L（QLU 实测） | 0.008016 | 0.1544 | **18.63** | **2.83** |
| 1000 mg/L | 0.026846 | 0.2107 | **7.59** | **3.07** |
| 5000 mg/L | 0.134228 | 0.5529 | **3.98** | **3.09** |

两条硬结论：

1. **边际账单收敛在 ~2.8–3.1 g/g，而平均账单随滴度塌缩（18.6 → 4.0）。**
   低滴度下"每克产物 18.6 克糖"主要是**生物量固定成本**，不是路径低效。
   对外汇报必须引用边际数（对比化学计量下限
   10C 产物/6C 葡萄糖 ≈ 1.55 g/g，边际 2.8–3.1 的效率约 50–55%），
   否则会把"规模不足"误读成"路线差"。
2. **氧气列在本模型中不可用**（`oxygen_column_interpretable: false`）：
   过氧化物酶体氧化酶把电子交给 O₂ 生成 H₂O₂，**过氧化氢酶（r_0255/r_0256）
   又把 H₂O₂ 变回 O₂**，O₂ 转运体在区室间搬运这个再生的氧——模型内部存在
   一个氧循环，因此**任何通气上限都不会束缚**（最低需氧恒为 0，且
   `internal_oxygen_cycling` 直接点名 r_0255 通量 0.418 等）。这不是
   "该路线不需通气"，而是"这个反应集可以被摆成这么说"。报告顶层字段与
   `oxygen_column_note` 都按"不可用"表述；要问真正的通气问题，需先
   给过氧化氢酶封顶（以其 H₂O₂ 输入为界）或把 O₂ 转运改为单向内运。

最小氧气点的受迫副产物只有 CO₂（0.460）——乙醇/乙酸/甘油/丙酮酸均为零：
在最小碳账单上模型选择全呼吸，没有溢出代谢。

## 三、与既有结论的衔接

| 上一轮结论 | 本轮修正/深化 |
|---|---|
| "IDP3 是 1:1 闸门但非产能瓶颈（自由穿梭可缓解）" | 缓解是名义上的：定价后 LP 弃用穿梭；**瓶颈根本不在区室化辅因子**，改造方向应转向碳供给/毒性/表达量 |
| "容量随碳供给按稳定摩尔产率上升 → 碳受限" | 细化为**两个账单**：平均（含生物量固定成本）与边际（~3 g/g，效率 ~50–55%）；低滴度引用平均会严重高估路径成本 |
| "氧气供给情景分析" | 本模型的氧循环（氧化酶-过氧化氢酶）使任何通气上限失效；已作为顶层警示字段与测试钉住，修复方案已写明 |

## 四、边界声明

- 全部为 **GEM 模型量**，非实验验证、非产量预测；titer 换算假设全体生物量
  以模型最大比速率生产满指定时长（`TITER_CAVEAT`）。
- kcat 输入为未校准预测；酶表达水平、底物毒性、分泌限制不在 GEM 内。
- 氧气列的不可用是**本模型的性质**（可修复，方案已给），不是该路线的性质。

## 五、测试

`tests/test_royal_jelly_acid.py` 新增 11 个测试，钉住：有价穿梭的 ATP 记账
位置与不可逆性、分数价格的 ID 独立性、非法版本/负价格的拒绝、
"免费无收益 + 正价即弃用 + 容量对价格/速率均不敏感"三件事、
氧物种按化学式跨 6 区室查找、交换集封闭不动生长、
边际 << 平均且夹在化学计量下限与 5 倍之间、
氧气列按"不可用"上报且点名两个过氧化氢酶、通气行全部"不受限"。
