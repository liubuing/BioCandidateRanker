# BioCandidateRanker 项目重新评价

评价日期：2026-10-05。评价对象：当前可复现实现及已保存证据。主要投稿目标：PLOS Computational Biology。

## 一、结论

**当前处于“可复现研究系统已建立，核心科学主张尚未通过独立验证”的阶段，尚不建议向 PLOS Computational Biology 提交正式研究稿。**

近期工作提高了数据来源、同源排查与统计比较的可审计性，但没有产生新的模型性能优势证据。项目有继续研究的基础；“新模型预测更准”“可可靠挑选高活性突变体”“已证明独立泛化”三项主张，目前都不成立。

还缺 91 条记录和 2 个家族，是既定外部评估的启动缺口。补齐这个缺口仅允许启动评估，不能自动补足方法创新、候选排序能力或生物学发现，也不能自动达到某个期刊分区。

## 三、现有能力与证据

### 1. 预测性能：有信号，未显示强基线优势

以下为同一 1,646 条内部测试集上的三种子指标均值；该测试集已被观察，属于内部诊断，不能当作全新外部确认。

| 方法 | RMSE ↓ | Pearson ↑ |
| --- | ---: | ---: |
| 当前 BioCandidateRanker 重训 | 1.41730 | 0.36770 |
| CatPred 适配版 | 1.38932 | 0.38967 |
| CataPro | 1.38759 | 0.43201 |
| UniKP | 1.40928 | 0.37768 |

当前模型 RMSE 的三种子样本标准差为 0.03568。相对 CatPred、CataPro、UniKP 的 RMSE 差值分别为 +0.02798、+0.02971、+0.00802；对应 95% 家族配对区间均跨零。

因此可以说当前平均误差更高、尚未证明优于这些对照；不能说已经证明显著更差，也不能把“不显著”解释为等效。输入、模型容量与适配方式仍有差别，比较的适用范围须在论文中说明。

历史实现 RMSE 1.39162 不能代替当前代码重训成绩。历史结果可复现是有价值的审计结果，但不构成新版优越性的证据。

### 2. 候选排序：已有结果不支持实际推荐用途

现有 EnzEngDB 三种子排序的 Spearman 为 −0.0256，Top-10% enrichment 为 0.5973，随机期望为 1。IMDH 已冻结景观中，BioCandidateRanker 的合并 Spearman 为 −0.1659、Top-10% enrichment 为 0.4734。

这两项任务的终点、同源性和数据条件不同，不能混合成一个统一泛化成绩；但两者都没有支持“可靠筛选高活性变体”的用途。仅补齐绝对 kcat 回归数据也不能补上这一用途证据。

### 3. 独立验证：尚未开始正式评分

当前记录数达到内部数量门槛的约 69.7%，家族数为 28/30，底物已超过 50。不能将这些比例平均成“论文完成度”。缺口不仅是两个家族：即使新加两个家族且各收满 20 条，也只补 40 条，仍少 51 条。

受来源、许可、完整构建、绝对单位和同源排查影响，公开候选转为有效记录的比例较低。因此不能按“找到三篇论文即可补齐”估算进度，也没有证据给出可靠完成日期。

### 4. 选模与校准：已经排除一个简单改法

训练分区内的单次家族外层留出中，NLL 选模与 RMSE 选模的 RMSE 为 1.48104 和 1.48669；差值区间跨零。RMSE 选模的 NLL 与区间覆盖变差，且平均变化主要来自一个种子。

这支持保留当前选模规则，不支持继续在已揭示的外层结果上挑轮次。它不是多折嵌套交叉验证，也未证明现有不确定性已经充分校准。

### 5. 工程与可复现性：项目的相对强项

已有训练、冻结、预测、配对比较和逐来源审计产物。本轮核验了对照报告引用的 **15 个预测输入文件的 SHA256**，均匹配；协议及最新外部池审计哈希未变。

这次复评没有重新训练或重跑测试，也不是完整软件发布审计。README 仍声明 CLI 检查点加载兼容性及缺少匹配校准产物的限制；若走软件论文路线，需要单独核验并解决交付问题。不能将研究工作流可复核等同于所有部署路径已经稳定。

## 四、与 PLOS Computational Biology 的距离

2026-10-05 核查的期刊官方标准重视原创性、创新、领域重要性、显著的生物学或方法学认识、严谨方法及充分证据。期刊不强制湿实验；Methods 和 Software 路线仍要求重要的新能力及广泛用途。[官方定位与标准](https://journals.plos.org/ploscompbiol/s/journal-information)、[投稿要求](https://journals.plos.org/ploscompbiol/s/submission-guidelines)。

## 五、建议调整工作重心

### 优先事项 A：把论文问题收紧

保留原定“绝对动力学预测何时能迁移为候选排序”的研究问题，但将它明确列为待验证问题。停止把模型胜过强基线作为默认结论。应先写清：要解释什么现象、哪些备选解释可以被区分、什么结果会否决假设。

已有负结果可用于提出假设；若主张普遍失效规律，需要新的独立来源支持。不能把几个已观察的失败案例重新命名后视为完成了一篇新贡献论文。

### 优先事项 B：继续补数据，但按来源价值排序

优先完整构建、多个绝对测量、可核查许可且无开发集命中的来源；FcCGT 的三条候选有明确后续核验路径。将高同源来源及时排除，将构建矛盾单列，避免反复耗费时间。

绝对动力学池与候选排序验证应分别管理。后者需要同一实验体系中的可比酶—底物测量和足够独立任务，不能用跨论文、跨条件的零散 kcat 直接组成“筛选成功”案例。

### 优先事项 C：用独立的开发方案检验解释

若继续研究条件信息、覆盖偏差或不确定性，先在训练／验证范围内定义受控比较、预算和失败判据。新的研究方案独立登记，不改写当前冻结协议，不使用已经揭示的测试或候选池成绩选方案。

### 优先事项 D：达标后再作投稿路线决策

- 若独立评估出现可靠且有生物学意义的新发现：继续组织 PLOS Computational Biology 的研究稿。
- 若准确率优势不成立，但产生经独立复验、可推广的适用边界或方法认识：评估比较／可靠性研究路线。
- 若仅得到“工程实现完整、性能相近、若干任务失败”：收紧主张，再按实际贡献重新选刊；不以补齐 300 条宣布目标达成。

上述是建议的下一阶段决策，不是已启动的新训练、已完成的新验证或录用承诺。
