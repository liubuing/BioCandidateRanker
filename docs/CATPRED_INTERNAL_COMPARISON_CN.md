# CatPred 正式内部测试与基线比较

日期：2026-09-28。

## 执行与核验

CatPred 30/30 个成员训练完成，种子 7、42、123 各10个成员。模型文件哈希、原保留成员与冻结训练协议已核验。正式测试前冻结 `configs/catpred_internal_test_protocol.json`，记录93项输入和实现哈希；比较计划保存在 `artifacts/catpred-mode-b/internal-test/comparison-plan.json`。

使用固定内部同源冷测试集1646行、830条不同蛋白序列。预测输入不含标签。采用官方冻结 ESM2 特征、batch 16、官方预测入口及每组10个成员的均值集成。每个种子完成一次正式预测；没有根据测试成绩调整参数、筛选成员或样本。三个预测文件均通过行数、样本ID顺序、有限值和哈希检查。

本结果必须标为“适配版 CatPred Mode B”：保留非标准残基映射至既有零嵌入 index20、CPU 特征缓存 mmap、独立成员种子修订。使用650M ESM2，而本项目历史模型采用8M编码器；模型容量、输入及验证选模规则不完全相同。结果属于同一数据划分的比较，不代表等计算预算或上游原实验的逐位复现。

## 配对统计与结论边界

沿用219个蛋白家族、5000次配对家族bootstrap，随机种子20260918；每次保留抽中家族的全部样本，对各固定种子的指标取平均。比较脚本及已有预测在 CatPred 结果出齐前冻结。此分析仍属于探索性分析，条件于当前划分与固定种子，没有多重比较校正。

RMSE差值定义为“比较模型 − CatPred”，负值表示比较模型误差较低：

| 比较模型 | RMSE差值 | 95%家族bootstrap区间 |
| --- | --- | --- |
| CataPro | -0.00173 | [-0.05264, 0.05358] |
| UniKP | 0.01996 | [-0.01476, 0.05603] |
| 本项目历史实现 | 0.00230 | [-0.05546, 0.06337] |
| 本项目当前代码回放 | 0.00628 | [-0.05245, 0.06807] |

以上比较的RMSE、MAE、Pearson差值区间均跨0。本项目历史模型的平均误差接近强基线，但没有证据支持显著优于 CatPred；区间跨0也不能证明等效或非劣效。不能据此宣布达到 PLOS Computational Biology 的录用要求。
