## 二、项目定位与组成

一个宿主感知的多模态酶候选评分系统：从蛋白质序列、底物分子图、反应上下文三类输入预测 log10(kcat)，并配套一整套证据治理基础设施（冻结协议、SHA256 身份绑定、审计脚本、可复现归档、交互工作台）。它的科学产出包含明确的负结果。

| 组成 | 规模 | 内容 |
|---|---:|---|
| 核心库 `src/biocandidate/` | 31 模块 | 主模型（分块蛋白质注意力 + 稀疏分子消息传递 + 哈希反应上下文 + 任务查询融合）、训练、校准、数据适配器、评估、GEM 上下文、蒸馏代理 |
| 命令行 | 23 子命令 | train / predict / evaluate / build-*-split / summarize-* 等 |
| 治理工具链 | 9 脚本 | 归档打包与验证、许可审计、数据可用性声明、池门控面板、外联对账、图 1 生成、就绪度面板 |
| 交互工作台 | 服务 + 双语前端 | 真实推理、批量、模型浏览、代谢通量、治理动作执行 |
| 配置契约 | 41 JSON | 13 份 SOTA 协议、5 个版本冻结清单、3 个 GEM 配置、许可清单、外部阻塞清单 |
| 文档 | 68 份 | 协议、结果、审计、外联、投稿件 |
| 测试 | 42 文件 / 275 测试函数 | 当前 315 通过 / 1 失败（见第六节） |
| 模型资产 | 50 个检查点 + 2 个蒸馏代理 + 3 套 GEM | 全部可加载 |
| 平台插件 | 已接入 Yeast-MetaTwin 平台 | 本报告同期完成，见第四节的拓展 |

### 项目自评（10-05 复评，原文口径）

- 当前处于"可复现研究系统已建立，核心科学主张尚未通过独立验证"的阶段
- 三项主张目前都不成立：**新模型预测更准**、**可可靠挑选高活性突变体**、**已证明独立泛化**
- 补齐缺口只允许启动评估，不能自动补足方法创新、候选排序能力或生物学发现

### 工程与科学的不对称

**工程侧超额完成**：49 次提交、360 个文件、双归档验证通过、9 个语料的许可有记录、工作台可跑真实推理、三套 GEM 融合并蒸馏出代理、平台插件已接入。

**科学侧原地冻结**：5 个科学工作流全部等待外部数据，而外联 8 份草稿 **0 封发出**；前瞻池距门槛差 99 条记录与 2 个家族，且从未被评分；核心结论仍是对现代基线无优越性、端点迁移失败。

含义：继续写代码的边际价值趋零，因为再多的工具也产生不了新的科学结论。

## 四、已具备的功能

### 4.1 可用且经过工程验证

- 从序列 + 底物 + 上下文预测 log10(kcat)，输出均值与标准差；保形区间功能就绪但因缺少匹配的校准工件而空转
- 同源冷划分构建（MMseqs2 30% 一致性）、归一化绝对动力学适配、分组不确定性校准
- 数据审计（UniKP / EnzEngDB / Lunzer）、经典基线评估、三种子实验编排
- 发布归档打包与验证（确定性：同提交重建逐字节一致）、去匿名化存款归档（22 个成员 49 处本地路径已清除）
- 语料许可审计、数据可用性声明起草、就绪度面板、外联对账、图 1 生成

### 4.2 可用但科学上未验证

- 交互工作台的完整推理链（真实跑通）
- **两个 GEM 蒸馏代理**：输入 8 维场景向量直接输出生长速率，测试集误差约 2–3%（较均值基线提升 24×/23×），但仅在采样分布内有效
- 酵母 kcat 约束 FBA 试点（GECKO 式）：外部锚点 0.274011 复现到小数点后 6 位，得出"路线 B 只需 0.54× CYP 酶量"
- **Yeast-MetaTwin 平台插件**（本报告同期完成）：BCR 已作为 `kcat_prediction` 插件注册进平台，平台插件测试 8/8 通过，端到端 smoke 返回 `ready`；清单如实标注 `blocked`

### 4.3 已实现但被外部数据阻塞

独立绝对动力学基准、受治理 Km 训练、受治理绝对活性训练、实验通量训练、前瞻候选排序评估——五项全部 `blocked_pending_external_data`。

### 4.4 失效或不完整

| 项 | 状态 |
|---|---|
| CLI `predict` / `evaluate` | torch ≥ 2.6 下失败（旧检查点含 `TorchVersion`）；`training.py` 属冻结不可改；工作台的 `safe_globals` 包装是可用路径 |
| 保形区间 | 无匹配校准工件，功能空转 |
| CatPred 原版全量运行 | 因非标准残基与主存不足失败，最终采用"适配版 Mode B"（非逐位复现） |
| 就绪度面板的池数字 | **落后**：读 7-27 旧审计（192/25/54），当前实为 209/28/66（原始）或 201/28/65（质量暂挂后） |
| 前瞻池 | 从未被评分，`predictions_permitted = false` |

## 五、科学结论边界

### 可以声称

| 结果 | 数值 |
|---|---|
| 模态诊断（三种子，内部测试） | 仅蛋白质 1.5025 → ＋底物 1.4454 → 完整 1.3916 |
| 历史 ESM-2 三种子（内部测试） | RMSE 1.3916 ± 0.0183，Pearson 0.3810 ± 0.0222 |
| 当前代码重训（内部测试） | RMSE 1.41730 ± 0.03568，Pearson 0.36770 ± 0.01771 |
| 现代基线（同划分重训） | CataPro 1.38759、CatPred 1.38932、UniKP 1.40928 |
| 基线对比 | 与三者的配对家族 bootstrap 区间**全部跨 0**——既不支持优越，也不支持等效 |
| 嵌套家族外层留出 | NLL 规则 1.48104 vs RMSE 规则 1.48669，差 +0.00565，CI [−0.01735, 0.03108]；不支持更换选择规则 |
| 端点迁移 | EnzEngDB 宏平均 Spearman 0.071；IMDH −0.166 |

### 不能声称

1. 新模型预测更准
2. 可可靠挑选高活性突变体
3. 已证明独立泛化

### 当前主问题（10-05 收紧后）

**在同一底物、同一测量条件下，绝对 kcat 预测能否可靠排列酶候选？** 评价对象为完整可追溯的酶构建，排序单位为原文可确认的独立实验组。
