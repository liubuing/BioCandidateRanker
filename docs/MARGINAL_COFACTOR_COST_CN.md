# 边际辅因子成本：从"总周转"到"该改造什么"

日期：2026-10-12。补齐王浆酸方向最后一块缺失的分析能力。

## 一、为什么需要它（总周转不够用）

此前辅因子会计只报**某一个最优点上的总周转**。这个数字**无法指导工程改造**——我实测过：把目标通量从 0.0685 拉到 0.274（4 倍范围），五个辅因子的总周转**完全不变**，因为目标被最大化时下限约束不紧，LP 每次都落在同一个顶点。

**有用的量是边际量**：每多产一单位产物，网络必须额外再生多少辅因子。

## 二、方法

固定目标通量为**等式约束**在分级水平上，改为**最大化生长**（即"产物—生长权衡"），然后对每个跟踪量做**最小二乘回归**：

- 斜率 = **每单位产物的边际成本**
- **同时报告 R²**——边际成本只有在响应接近线性时才是单个有意义的数字；R² 低说明成本随区间变化，不能只引斜率

**不施加生物量下限**：固定产物通量本身就已决定生长上限，再加下限会让曲线变成受约束的切片而不是权衡本身（这一点写在函数文档里）。

## 四、三个可直接用于决策的读数

**① NADPH 是唯一的大正成本（+15.6/产物，R²=0.996）**
拟合极好，说明这是**稳定的单个数字**而非区间现象。而它的 74% 供给来自磷酸戊糖途径（`r_0466` ZWF1 + `r_0889` GND1）——靶点明确。

**② H₂O₂ 边际成本 +3.012/产物，是 POX1 自身贡献的 3 倍**
POX1 每产物产生 1 H₂O₂，但边际成本是 3.0——差额来自为平衡氧化还原而并行运行的其他链长酰基-CoA 氧化酶。**这条只有边际分析能给出**：看总周转会以为是 1，实际是 3。对"要不要工程化过氧化物清除能力"是直接相关的判断。

**③ ATP 与 NADH 是负成本**
产产物**释放** ATP（−8.26/产物），因为产物路线比它替代的生物量合成更省 ATP。所以**ATP 不是瓶颈**，不应作为改造目标。

## 五、接口

通用实现放在 `fba_context.marginal_cofactor_cost`（场景约束由调用方以 `context` 回调注入，因此对模型与场景都无关）。王浆酸专用入口：

```bash
python -m biocandidate.royal_jelly_acid --marginal --route A
python -m biocandidate.royal_jelly_acid --marginal --route B --close-pox1
```

输出包含逐点曲线、边际成本与 R²、按成本排序、以及最大正成本标注。

## 六、边界

- 全部是**模型量**：FBA 稳态、无调控、无限酶容量。边际成本说"网络必须多再生多少 NADPH"，**不说细胞能否以那个速率做到**——后者需要 kcat 约束（试点已做）或实测池
- 边际成本是**局部线性摘要**，R² 已随附；R² 低的量（ATP 0.922、NADH 0.982）不应作为单一数字引用
- 产物的等式约束是模型侧的"强制生产"，不代表菌株真能维持该通量
