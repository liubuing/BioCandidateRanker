## 3. 接受池如何处理

1. 保留当前 209 条及原始全局家族限额。不得为了凑大排序组恢复此前被限额排除的记录，也不按测量高低或模型预测筛选。
2. 用来源、底物和完整反应条件确定排序组。跨底物数据不合并；共享亲本、同一研究及复用测量的依赖关系保留到后续统计设计。
3. 先完成实验组核验，再以元数据和开发集模拟确定最小组规模、精度要求、并列处理及来源/家族相关性处理。当前“至少 3 个序列”仅为盘点阈值。
4. 全部既有外部评估门槛和新的排序方案冻结完成后，才运行统一基线和本模型。当前没有新增性能结论。

## 4. 后续顺序与停止条件

**第一优先：闭合已有较大候选组。** 先查 S-EPMC12645435 的 8 条肌苷记录、PMC11659886 的 21 条硫酸化底物记录：逐构建补充初始速率、酶量归一化、拟合和重复/误差定义。它们仅为优先核验对象，不能预先视为两项独立验证。原文不能支持的字段标记未知，不编造。

**第二优先：完成条件拆分。** OleT 的 10% 乙醇子组仅 3 个不同序列，暂作小组可行性候选；2.5% 子组只有 2 个。LRRK2 拆分后仍缺反应条件，继续暂挂。正式最低规模尚未冻结，不凭这一轮结果临时降低门槛。

**第三优先：定向补新来源。** 优先公开原文/补充材料中具有同底物、同条件、多个可追溯构建及绝对 kcat 的研究。可用“至少 5 个构建”作为检索优先级，不能冒充新的冻结纳入门槛。同时优先新增全局家族和独立研究来源；依次检查许可、构建、条件、跨论文重复、开发集重叠和全局限额。继续补足原协议的 91 条、2 家族差额。

**第四优先：有限追踪暂挂来源。** 四个暂挂组只有找到明确公开证据才解除暂挂；不得把室温、预孵育或色谱温度当作缺失动力学温度。FcCGT 的 3 条待核测量另需完整构建和跨文献去重；PMC11213884 当前仅支持固定底物浓度下比活性，不继续作为已验证绝对 kcat 来源推进。
