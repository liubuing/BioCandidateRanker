# 区室化辅因子会计与 IDP3 瓶颈：基于 QLU 2025 的下一步

日期：2026-10-12。起因：QLU 2025（JAFC, DOI 10.1021/acs.jafc.5c02058）把 P450 放进**线粒体**做隔室化表达。这促使我核查本项目的路线在哪个区室——结果暴露了一个我此前的错误。

## 一、更正：我此前报的 NADPH 成本是错区室的

QLU 的核心动作之一是"隔室化"。核查后发现：

**本项目的 10-HDA 路线是过氧化物酶体的**：P450 反应 `CAND_T2DEC_OMEGA_HYDROXYLASE_P` 消耗 **`s_1215` = 过氧化物酶体 NADPH**，而此前辅因子会计声明的锚点是**胞质副本 `s_1212`**。

分池重算：

| 池 | 边际成本/产物 | R² | 说明 |
|---|---:|---:|---|
| **过氧化物酶体 NADPH**（路线直接消耗）| **+1.000** | 1.000 | **纯化学计量** |
| 胞质 NADPH（网络重排）| +15.595 | 0.996 | **不是路线直接需求** |
| 过氧化物酶体 NADH | +3.012 | 1.000 | |
| 过氧化物酶体 ATP | 0.000 | 1.000 | 不消耗 |

**+15.6 的准确含义**：网络为支持生产而重新布线的总循环增量，主要由 `r_4574`（+0.966，**同时供乙酰-CoA**）与 PPP（`r_0466`/`r_0889` 各 +0.885）承担。我顺带验证了"过氧化物→NADPH"的猜想，**不成立**：H₂O₂ 由过氧化氢酶与硫氧还蛋白过氧化物酶清除，都不直接消耗 NADPH。

## 二、实现：区室感知的辅因子会计

新增两个通用能力（都在 `fba_context`）：

- **`compartmental_copies(model, metabolite_id)`** —— 按**代谢物名称精确匹配**展开该化学物种的全部区室副本。声明的 ID 作为身份锚点，只有它自己的名称被展开，避免同名相似物被误纳入
- **`cofactor_turnover_by_compartment(...)`** —— 逐区室报告总周转、净生成、是否活跃、主要来源。已接入 `run_fba_context`（`cofactor_by_compartment` 字段）与路线分析

锚点场景（容量 0.274011）的实测结果：

| 辅因子 | 有通量的区室 |
|---|---|
| NADPH | c=4.635、**p=0.274**、m=0.008、er/erm≈0.001（lp 为零）|
| NADH | c=1.459、m=1.462、**p=0.822**、erm≈0.001 |
| ATP | c=5.162、m=2.739 |
| 乙酰-CoA | c=2.204、m=1.000、**p=0.822** |
| 丙二酰-CoA | **仅胞质 1.928** |

三点读数：

1. **过氧化物酶体 NADPH = 0.274 = 容量本身** —— 严格 1:1，与下面的瓶颈扫描互相印证
2. **过氧化物酶体 NADH = 0.822 ≈ 3× 容量** —— 来自过氧化物酶体的 β-氧化步骤（3-羟酰-CoA 脱氢酶等）
3. **丙二酰-CoA 只在胞质** —— FAS 在胞质，所以"丙二酰-CoA 供给"是胞质问题，与过氧化物酶体路线的区室不通

## 三、核心发现：IDP3 是 1:1 的容量闸门

查过氧化物酶体 NADPH 的**全部**产生与消耗反应：

**产生者只有一个**：`r_0661` = 过氧化物酶体异柠檬酸脱氢酶，**基因 `IDP3`（YNL009W）**，边界 `(0, 1000)` —— 模型假设容量无限。

**消耗者四个**：两个 2,4-二烯酰-CoA 还原酶 + 路线的两个 P450 候选。

**且模型里没有跨区室转运反应**——胞质磷酸戊糖途径与过氧化物酶体池不连通。

### 容量扫描（新增 `enzyme_capacity_scan`）

给 IDP3 的通量加上限，重新最大化目标：

| IDP3 通量上限 | 目标容量 | 状态 |
|---:|---:|---|
| 0.020 | 0.020000 | **受限** |
| 0.050 | 0.050000 | **受限** |
| 0.100 | 0.100000 | **受限** |
| 0.200 | 0.200000 | **受限** |
| 0.300 | 0.300000 | **受限** |
| ≥0.4 | 0.302724 | 不受限（达到满载）|

**拐点（二分细化）：0.302724 = 无约束目标本身，即 1.0000 × 参考通量。**

### 这条结论的准确表述

> **在 IDP3 通量低于产物通量时，目标容量完全等于 IDP3 的通量。** 因此 **IDP3 必须以 ≥1:1 的周转速率工作**才能支撑给定的 10-HDA 通量——每产一分子 10-HDA 需要 IDP3 转一次。

**这给出一个明确且与常规做法不同的工程靶点**：过氧化物酶体还原力的瓶颈是 **IDP3**，而**不是**经典的胞质 ZWF1/磷酸戊糖途径——在模型里两者不连通，强化胞质 PPP 无法供给这条路线。

**顺带修正一个方法问题**：网格分辨率的拐点报 0.4，**二分细化后是 0.3027**——粗网格把要求高估了 32%。因此 `enzyme_capacity_scan` 内置了二分割细化，文档里也写明了这一点。

## 四、模型能碰与不能碰的（对照 QLU 2025）

| QLU 动作 | 模型 | 现状 |
|---|---|---|
| ① 重构 β-氧化 | **能** | 过氧化物酶体已在模型内，路线已建 |
| ② **线粒体隔室化 + 伴侣折叠** | **半能**：区室可建模（不同辅因子池）；**伴侣折叠不可建模** | 区室核算已就绪；三区室对照待做 |
| ③ **强化 NADPH 供给** | **能，且已定位靶点** | **IDP3 瓶颈已量化** |
| 底物毒性 → 乙基癸酸酯 | **不能** | 无毒性项；酯型底物只表现为多一步水解 |

## 五、边界

- 全部是**模型量**：FBA 稳态、无限酶容量（IDP3 的瓶颈是通过**人为加约束**暴露的，不是模型自发识别的）
- IDP3 的 1:1 是**化学计量结论**，可靠；但"IDP3 实际能否达到该通量"需要它的 kcat 与表达量——模型给不了
- 区室划分**取决于模型自身的区室定义**；真实酵母的过氧化物酶体-胞质还原力交换可能通过尚未建模的穿梭系统发生，因此"两池不连通"是**模型内的事实**，不一定是生物学事实
