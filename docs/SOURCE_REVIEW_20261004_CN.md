## Fordyce 的大样本实际包含什么

门户 JSON 包含 **23,765 行、13 个研究键**。以门户年份和测量类型作初筛：

| 研究键 | 直接 kcat 行数 | 当前结论 |
|---|---:|---|
| Markin2021_Science | 1018 | 门户年份早于 2023，不符合时间门槛 |
| Lee2025_AnalChem | 41 | 唯一标为 2023 年以后且含直接 kcat 的研究；全部属于 PafA |
| 其余 11 个研究键 | 0 | 存在 Kd、Ki、kcat/KM、折叠及其他参数，不能作为直接 kcat 行数 |

特别是 Markin2023_PNAS 的 2057 行均标为 Ki；Lee2026_bioRxiv_SHP2 含 729 行 kcat/KM，但没有标为直接 kcat 的行。不能将它们当作数千条目标标签。
这些是门户元数据统计，不是已核实原始发表日期、可用标签或独立样本数。不同端点本身有研究价值，只是不满足当前主端点。

门户仓库 API 的 license 为 null，根目录仅有 README 与 data.json，README 未声明许可。公开可下载不等于满足 CC0/CC BY 4.0。
Lee2025 的原始研究对应关系、原始表与独立数据许可仍须确认。即使 41 行全部有效，也不能假定能增加 41 条记录或多个家族；同一家族最多保留 20 条，还需同源排除与重复审计。

已记录仓库提交 `47d9dd2aca002773022a385fc7691addf4c84600` 和实际下载文件哈希。数据来自门户当时的公开 JSON；仓库提交仅作同时期上下文，不声称下载文件已逐字匹配该提交。

## 旧来源重审

### 人 G6PD：同源排除已有明确证据

论文 DOI：10.3390/ijms26178464。此前在一轮优先级筛选中因不足 10 条而搁置，本轮重新开展序列预筛。
人 G6PD 参考序列 UniProt P11413 为 515 aa。参考序列在开发集命中 **100% 一致、双向全长覆盖**。
对论文报告的六个变体逐位核对原残基后查询，野生型及六变体全部有冻结阈值下的合格命中。
因此该来源不能作为新同源冷家族纳入；不再继续为其整理完整融合构建或测量表。
查询基于公开参考与论文变体定义，并非取得了实测质粒的完整测序文件。

### 植物 SABATH：恢复有效线索，序列核验待完成

论文 DOI：10.1093/gbe/evae016。取得了原始全文、BioStudies 文件索引和 8 页补充 PDF。
已渲染检查补充图 S2：祖先序列比对确实存在，但 PDF 文本提取没有返回图中的氨基酸字母。
所以不能说“来源没有序列”；下一步应取得机器可读序列，或对图中序列进行逐位、双重核对的转录，并核对构建和位点编号。
Figshare 数据 API 本轮返回 HTTP 403，已记录访问阻塞。未用近缘序列替代祖先酶，也未对猜测序列运行同源检查。

## 对集中筛查计划的影响

大数据门户未提供立即可导入的多家族补充。继续任务应优先恢复 SABATH 的可审计序列，并确认 Lee2025 原始数据许可；同时拓展其他原始研究，不能把这两条线索视为足以填补缺口。
本轮不更改冻结协议、不生成模型预测、不将待审记录计入接受池。
