# 前瞻 kcat 湿实验 Panel 协议（草案）

版本：0.1  
日期：2026-10-20  
状态：**草案，未冻结**。冻结前不得产生正式标签，也不得用本模型预测值选择家族、构建体或底物。

## 1. 目的与边界

本协议定义一个**独立、前瞻、盲法**的酶 kcat 湿实验 panel，用于回答：

> 在未参与训练和调参的酶家族上，BioCandidateRanker 的绝对 kcat 预测能否可靠地优于已发表基线？

它与现有 209 条文献时间池**分开管理**：

- 本 panel 是新产生、未发表的测量，不能自动计入文献池的 300 条 / 30 家族 / 50 底物门槛；
- 只有将来按文献池的论文日期、CC0/CC BY 许可、精确构建体和同源冷条件重新审计后，才可能并入；
- 已用于本 panel 最终评估的记录，不得再次宣称为“未见过的确认集”；
- 本 panel 只验证 kcat，不验证工业 titer、产率或放大。

## 2. 科学问题与假设

**主问题**：在同一底物、同一测定条件下，绝对 kcat 预测能否可靠排列并定量预测未见家族的酶？

| 编号 | 假设 | 判定 |
|---|---|---|
| H1 | 本模型相对 UniKP 的 `log10(kcat)` 配对 RMSE 改善 ≥5%，且家族 bootstrap 95% CI 不跨零 | 主检验 |
| H2 | 家族等权后方向一致，且至少 6 个家族可评估 | 支持 H1 的稳健性 |
| H3 | 排序指标（Spearman、pairwise accuracy、top-decile enrichment）不差于随机 | 次要、描述性 |

H1 的 5% 是项目预设的**实际改善幅度**，不是期刊要求；若 CI 跨零，只能报告“证据不足”，不能称为等效。

## 3. 设计

| 设计单位 | 数量 | 说明 |
|---|---:|---|
| 主家族 | 8 | 另设 2 个备用家族，按预排顺序启用 |
| 每家族构建体 | 8 | 不同的最终测定链，不是同一构建体的重复孔 |
| 每构建体底物 | 3 | 有明确结构、可定量、与家族催化逻辑一致 |
| 独立蛋白批次 | 3 | 每构建体 3 次独立表达/纯化 |
| 正式浓度点 | 8 个非零 + 零底物对照 | 最高浓度至少 5×拟合 Km |
| 技术重复 | 每点 2 孔 | 技术孔不单独计为记录 |
| 目标合格记录 | 108–128 条 | 上限 160 条；每家族 ≤20 条 |
| 规模 | 8×8×3 = 192 个组合 | 约 10,368 孔，另加标准曲线/空白/复测 |

**分析单位**：同一构建体、同一底物、同一固定条件下的独立蛋白批次结果，按预注册规则聚合为**一条记录**。技术重复、同批多孔、同一次蛋白制备的重复测定都不能凑记录数。

**样本量边界**：108–160 条、约 8 个家族足以做有用的独立验证，但不足以检出内部约 1.3% 的微小 RMSE 差异；本 panel 的目标是 5%–10% 量级的改善。实验前用开发数据或保守模拟做按家族的功效敏感性分析，且不得查看新测试误差后扩样或停样。

## 4. 家族、构建体与底物选择（全部 label-independent）

### 4.1 家族

1. 从约 12 个实验室熟悉、可溶表达、底物可购、读出成熟的候选家族中筛选；
2. 每个候选家族先做序列审核：最终测定链、标签、linker、切割 scar、突变、加工末端、多组分化学计量；
3. 对 UniKP 开发集做 **MMseqs2 30% identity / 80% coverage / coverage mode 0** 同源筛查，命中者排除；
4. 家族多样性优先于催化类别多样性；酶学类别不等于独立序列家族，最终家族数由全局 MMseqs 审核确定；
5. 预排 8 个主家族和 2 个备用家族；备用启用顺序在协议冻结时固定，不按模型分数或早期结果调整。

### 4.2 构建体

- 每家族 8 个最终测定构建体；优先覆盖家族内序列/结构多样性，而不是按预测 kcat 挑“看起来快”的；
- 可包含 WT、自然变体、结构域截断或预先设计的点突变，但名单必须在看到实验标签前冻结；
- 每个构建体记录完整最终链、表达载体、标签、纯化方式、是否切除标签；
- 不得用本模型、UniKP 或其他预测值筛选构建体。

### 4.3 底物

- 每构建体 3 个有依据的底物；同一家族内尽量使用同一底物组，便于家族内比较；
- 每个底物必须有 PubChem CID 或精确 isomeric SMILES；
- 固定辅底物、辅因子、金属、氧气、偶联酶必须在同一测定条件下验证饱和或非限速；
- 底物溶解度不足时，先在可溶范围内扩展浓度；无法达到饱和则按预注册规则排除，不能强行套用 Michaelis–Menten。

## 5. 纳入与排除

### 5.1 纳入

每条记录必须同时满足：

- 直接实验 `kcat`、`Km` 或 `kcat/Km`，不是预测值、相对活性、fitness、%WT 或 RFU/min；
- 精确最终测定链（含标签、linker、切割 scar、突变、加工末端）；
- 单一明确底物 + PubChem CID / 精确结构；
- 酶摩尔浓度或活性浓度，以及按亚基/复合体计量的说明；
- 原始浓度系列、初速度、标准曲线、空白、板位、仪器、日期、操作者；
- 固定组分饱和或偶联非限速的证据；
- 3 次独立蛋白批次（或预注册的等效独立性证据）；
- 来源、许可、SHA256、行/单元格溯源。

### 5.2 排除

- 只有相对活性、终点读数、单点速率、未达饱和且无法拟合；
- 酶浓度未记录，或把总蛋白量直接当活性酶量；
- 底物结构不明、混合物、聚合物、未定义化学修饰；
- 固定辅底物/辅因子/氧气未饱和，或偶联步骤可能限速；
- 表达失败、纯化失败、未检出、无法拟合——这些不删除，写入 `panel_attempts.csv` 并标记 `failed`/`inactive`/`censored`；
- 任何按模型预测或实验结果选择性排除的样本。

## 6. 湿实验 SOP 与质控

### 6.1 蛋白制备

- 每构建体 3 批独立表达/纯化；记录批次、日期、载体、宿主、诱导条件；
- 纯度目标 ≥90%（SDS-PAGE/Coomassie）；记录浓度、稳定性、聚集状态；
- 浓度用适配缓冲液的 A280、Bradford 或活性位点滴定；明确是按亚基还是复合体计量；
- 活性比例不清楚时保留定量依据和局限，不能把总蛋白当活性酶。

### 6.2 动力学测定

- 每家族固定温度、pH、缓冲液；记录实际测定条件；
- 底物系列约 0.1–10×预实验 Km，正式曲线最高点 ≥5×拟合 Km；
- 8 个非零浓度 + 零底物对照，每点 2 孔；随机化板位，分散家族与批次；
- 初速度区间底物消耗 ≤10%；至少 4 个时间点确认线性；
- 每板设无酶空白、零底物对照、产物标准曲线、稳定参考酶/参考批次；
- 固定辅底物、辅因子、金属、氧气、偶联酶：做饱和/非限速验证，或采用互变底物/全局拟合；
- 技术重复 CV 通常 ≤15%；独立蛋白批次 kcat CV 通常 ≤25%；超限先排查，按预注册规则复测，不能按模型误差决定去留。

### 6.3 拟合

- 首选 Michaelis–Menten；底物抑制用底物抑制项；固定组分未饱和时用全局/互变底物拟合；
- 报告拟合模型、参数、标准误/置信区间、R²、残差模式；
- `kcat = Vmax / [E]active`；不能从单点速率直接推 kcat；
- 每条记录保留原始曲线和拟合输出，不只保留汇总值。

## 7. 盲法、保管人与冻结顺序

| 步骤 | 谁做 | 产物 |
|---|---|---|
| 1. 协议冻结 | 计算负责人 + 实验负责人 | 带时间戳的协议、分析计划、停止规则 |
| 2. 家族/构建体/底物 roster 冻结 | 实验负责人 + 独立审核 | `panel_roster.csv`，label-independent |
| 3. 模型/基线/代码冻结 | 计算负责人 | checkpoint、UniKP 版本、预测脚本、环境哈希 |
| 4. 湿实验与质控 | 实验组 | 原始数据、批次记录、QC 报告 |
| 5. 记录冻结 | 实验组 + 质控 | `panel_records.csv`、`panel_attempts.csv`、排除理由 |
| 6. 盲预测存入 | 计算组 | `blind-predictions.csv` + SHA256 |
| 7. 标签揭示 | 独立保管人 | 标签 CSV，仅一次 |
| 8. 一次性评估 | 计算组 + 保管人 | 最终评估收据，不可重跑 |

- 实验人员不知道模型预测排序；计算人员在看标签前不知道样本映射；
- 独立保管人掌握标签和样本映射，不参与模型调参；
- 预测必须先于标签揭示存入；预测文件一旦存入不可覆盖；
- 最终评估只运行一次；结果不能用于调参、选模型或改统计规则；
- 任何偏离协议的行为在揭盲前记录，揭盲后不得修改主分析。

## 9. 统计分析计划

### 9.1 主分析

- 主终点：`log10(kcat)` 的配对 RMSE 差值（本模型 − UniKP）；
- 在同一记录集上比较；缺失/删失按预注册规则处理，不做插补；
- 以**家族**为抽样单位做配对 bootstrap（至少 10,000 次），报告 95% CI；
- 同时报告家族等权均值与逐家族结果；
- 预设“值得进一步推进”的门槛：相对 UniKP 的 RMSE 降低 ≥5%，且 95% CI 不跨零。

### 9.2 次要分析

- MAE、Pearson、Spearman、pairwise accuracy、top-decile enrichment；
- 三倍/十倍误差范围内比例；
- 按家族、底物类别、酶长、读出方式分层（小样本层只作描述）；
- 不确定性覆盖：报告名义 90/95% 区间的实际覆盖，并注明校准工件是否匹配；
- 模型间比较使用完全相同的记录；报告各模型无法预测/无法评估的比例。

### 9.3 不做什么

- 不用新标签重新训练、微调或选择 checkpoint；
- 不因结果不显著而改主终点、改家族集合或反复扩样；
- 不把技术重复当独立样本；
- 不把 kcat 结果外推到工业 titer、产率或放大。

## 10. 偏离、停止与降级规则

- 所有偏离在发现时记录：日期、原因、影响范围、是否在揭盲前；
- 第 8 周若少于 6 个家族建立可接受方法，启用预排备用家族；仍不足则暂停扩展采购，重新核算预算与设计；
- 若某家族表达/纯化/测定系统性失败，记录并排除该家族，不降低其他家族的纳入标准；
- 若合格记录 <108 条或可评估家族 <6 个，按预注册规则报告“样本不足”，不宣称确认性结论；
- **任何情况下都不降低 20 条/家族上限、不删失败记录、不按模型表现挑选剩余样本。**
