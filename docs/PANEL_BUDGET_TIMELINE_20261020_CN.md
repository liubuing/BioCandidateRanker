## 3. 分阶段投入

| 阶段 | 金额 | 覆盖内容 | 释放条件 |
|---|---:|---|---|
| 第一阶段：预实验 | 3–5 万元 | 家族/序列预审、16 个构建体、32 个组合方法开发 | 协议与 roster 冻结；至少 8 个可行家族 + 2 个备用 |
| 第二阶段：主实验 | 剩余 10.4–25.1 万元 | 其余构建体、3 批独立蛋白、正式曲线、质控与复测 | 第 8 周达到至少 6 个合格家族、读出与质控可接受 |
| 第三阶段：收尾 | 含在总预算 | 行级审核、家族 cap、盲态评估、数据包、图表 | 合格记录与家族数达到预注册目标 |

**第 8 周阶段门**：若少于 6 个家族建立可接受方法，或有效组合明显不足，不释放全部采购；优先启用预排备用家族，重新核算预算。判断依据是实验可行性与质控，不是模型表现。

## 4. 时间线

以实验人员到位、平台可预约、采购启动为第 1 周。

| 周 | 工作 | 交付/门槛 |
|---:|---|---|
| 1–2 | 家族与序列预审、底物清单、角色分工、询价 | 至少 8 个可行家族 + 2 个备用；可下单表格 |
| 2–6 | 第一批 16 个构建体制备、32 个组合方法开发 | 表达/纯化/读出可建立；失败记录保留 |
| 6–8 | 预实验复核；冻结质控、样本数、统计方案 | **G2：≥6 个家族方法可接受**；否则暂停扩展 |
| 5–12 | 分批扩展其余构建体；完成独立蛋白制备 | 每构建体 3 批；纯度/浓度/稳定性记录 |
| 8–18 | 正式浓度系列、固定组分验证、预定复测 | 8 非零点 + 零对照；≥5×Km；QC 通过 |
| 18–20 | 行级审核、家族 20 条 cap、冻结队列 | `panel_records.csv` / `panel_attempts.csv` 完整 |
| 20–22 | 盲预测存入、一次性揭盲、基线比较 | 预测先于标签；只评估一次 |
| 22–24 | 图表、结果、讨论、数据包、稿件 | 结论与实测一致；许可/引用核查 |
| 24–32 | 困难情况缓冲 | 表达失败、底物难购、色谱依赖、人员不足 |

任务允许跨阶段重叠，但**扩展采购应在阶段门后分批释放**。

## 5. 人员与设备

| 角色/设备 | 需求 |
|---|---|
| 湿实验人员 | 2 人，每人约 4–5 个全时人月；分别主责蛋白与动力学并互相复核 |
| 计算与数据人员 | 1 人，约 1–1.5 个全时人月，分散覆盖全周期 |
| 酶学负责人 | 每周约半天，审核动力学模型、异常曲线和条件 |
| 独立数据保管人 | 全周期约 0.2–0.4 个全时人月；不参与模型调参 |
| 基础平台 | 分子克隆、培养/离心、蛋白纯化、电泳、蛋白定量、低温保存 |
| 核心测定平台 | 可控温连续读数吸收/荧光酶标仪；按需预约 HPLC 或 LC–MS |
| 计算资源 | 现有可运行冻结模型的工作站；一般不需新购训练服务器 |

- 预约约 **100–160 小时**酶标仪机时作为容量缓冲；
- 蛋白生产预计每周 **12–20 个独立小批次**；
- 若只有 1 名湿实验人员，周期应重排到 **28–36 周**，不能把相同工作量压进 20–24 周。

## 6. 预算释放与采购规则

1. 第 1–2 周只做预审与询价，不一次性采购全部基因；
2. 预实验额度 3–5 万元，按本单位采购流程执行；
3. 第 8 周阶段门通过后，才释放主实验采购；
4. 备用家族启用先使用预备费；超出预备费需重新定额，不能承诺无限补做；
5. 任何“因为模型结果不理想而加做”的采购都不在预算内，也不符合协议；
6. 外包蛋白生产/动力学测定需按独立批次数、浓度点、原始数据和失败交付条款重新报价，不能把“合成基因”报价当整套实验成本。

## 7. 超预算触发条件

以下情况会显著增加单条记录成本，应在启动前评估：

- 膜蛋白、复合体、翻译后修饰或普遍低表达；
- 自定义昂贵底物、放射性/特殊标记底物；
- 主要读出依赖 HPLC 或 LC–MS；
- 需要大量条件筛选才能建立饱和曲线；
- 需要额外活性位点滴定或结构确认；
- 单家族贡献过多，触发 20 条 cap 后仍需补其他家族。

出现上述情况时，先调整候选体系或索取分项服务报价，不直接扩大总预算。

## 8. 不包含的费用

- 论文版面费、开放获取费；
- 机构管理费、税费、汇率差异；
- 新购大型仪器（酶标仪、HPLC、LC–MS 等）；
- 大规模结构解析、冷冻电镜、质谱组学；
- 工程突变体筛选（可选追加，约 14–26 万元、12–16 周）；
- 工业化放大、发酵中试、下游纯化与成本核算。

## 10. 主要风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 表达/纯化失败 | 构建体不足 | 预排备用家族；保留失败记录；不按模型挑样本 |
| 底物不溶/不饱和 | 无法拟合 kcat | 扩展可溶浓度；全局/互变底物拟合；仍不行则排除并记录 |
| 固定组分/偶联限速 | kcat 被低估 | 饱和验证；换偶联酶/读法；全局拟合 |
| 单家族贡献过多 | 家族不均衡 | 预注册 20 条/家族 cap |
| 合格记录 <108 | 无法做确认性结论 | 按预注册报告“样本不足”；不降低门槛 |
| 只有 1 名湿实验人员 | 周期延长 | 重排到 28–36 周或增加人员 |
| 底物/平台成本超预期 | 预算超支 | 第 8 周重新核算；调整候选体系；不无限补做 |
| 模型结果不理想 | 加做冲动 | 协议禁止按结果扩样；负结果如实报告 |
