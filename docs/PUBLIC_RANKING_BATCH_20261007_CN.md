## 什么时候能运行

当前受阻的是正式外部评价资格，不是已经完成训练的模型缺少新一轮训练。冻结项目协议要求：

1. 至少 300 条合格记录、30 个全局家族、50 种底物。按当前 201 条保留资格的口径，至少仍缺 99 条和 2 家族。新增候选不会未经审查直接抵扣缺口。
2. 最终排序组的来源一致性、实验条件、端点及依赖关系得到处理。暂挂数据可以不进入最终集，不要求所有历史问题都解决。
3. 冻结评价指标、最低组规模、误差与并列处理、统计推断、比较模型版本和检查点。
4. 新的全局审计及纳入清单通过后，才能执行正式预测和比较。

300/30 是项目既有冻结门槛，不是期刊统一要求。当前未设可保证的开跑日期：公开数据是否合格、同源排查是否通过尚不确定，不能把下载完成日期等同于评估日期。

下一执行节点是将两个优先新来源推进到明确的纳入或暂挂/排除结论，再更新剩余缺口。若公开数据持续无法满足原目标，应单独提出有理由的研究设计修订并保留原失败记录，不能为了开跑静默降低冻结门槛。原始清单中已有 83 条共同条件候选也没有因此取得评分权限。
