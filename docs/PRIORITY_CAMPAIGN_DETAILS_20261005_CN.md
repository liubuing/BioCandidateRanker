# 两个优先排序组的深入核验

日期：2026-10-05。承接 18 组分类后的下一步，核验已有 8 条肌苷记录和 21 条硫酸化底物记录，并初筛两个新来源。

## 1. 执行结果

已核对两个研究的正文、补充方法、图表和接受池候选 ID，共 **29 条已有记录**。逐条保存酶浓度、亲本、误差解释及预测禁用标记。新增接受记录 **0**，接受池历史审计仍为 **209 条、28 家族、66 底物**。原池和冻结协议哈希一致；未运行模型预测。

本轮找到了额外的原文一致性问题。历史接受池数量不代表所有记录已通过新排序任务的质量审查，不能把本轮 29 条直接当成可评分测试集。

## 2. 肌苷组：补齐时间曲线证据，但需暂挂原文一致性核查

来源：[CtNDT 原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC12645435/)，DOI：10.1021/acschembio.5c00120。

- 补充 PDF 第 50、52—54 页 Figure S4 展示全部 8 个肌苷候选的时间曲线和速率拟合；正文 Figure 3 明确将这些用于初始速率分析。现已完成相关页面的视觉核验，未从图片重拟合数据。
- 第 7、24 页支持逐构建酶量：Y7A 为 0.8 μM，其余本组构建为 1 μM；第 54 页说明产物校准。此前泛化的“0.5—1 μM”不能直接套到全部肌苷记录上，0.5 μM 对应另一底物条件。
- **重复数冲突：**正文 Figure 3 为三次重复，补充方法为两次。正文说明误差来自拟合标准误，补充 Table S3 的 ± 未明确为标准差。原 CSV 的 `kcat_sd_s-1` 列名不能作为 SD 的来源证据；本轮在独立审计覆盖层记录限制，未改写原表。
- **D62N 图表尺度疑点：**Table S3 给出的 kcat 与酶量意味着 Vmax 为 0.12 μM/min，而第 54 页图中一个测量速率约为 0.75 μM/min。两者在所报条件下不一致。这里是图表质量核查，不据图猜测替换标签，也不按活性大小筛选候选。

**处置：**保留 8 条原始数据，排序资格暂挂；需公开更正、可核验的原始数据或其他可靠解释解决上述冲突。时间曲线有图示支持不等于已重新验证线性区间。

## 3. 硫酸化底物组：初始速率与归一化有据，误差解释待定

来源：[6-sulfo-β-GlcNAcase 原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC11659886/)。

- 正文动力学方法明确使用连续监测的初始释放速率，采用相同缓冲条件下的 4MU 标准曲线，拟合公式显式包含酶浓度 Et，因此不同酶量已具备方法层面的归一化依据。
- 21 个构建对应 **WG、YG、F3-ORF26 三个亲本，各 7 条**。保存亲本依赖块；不能把它们当成 21 次独立实验，也不能把同一研究拆成三个独立来源来增加统计样本量。
- 正文明确三次重复，但当前已核方法未区分生物/技术重复，也未定义动力学表中 ± 的统计含义。保留原始误差字段为未定义，不转换成 SD、SEM 或置信区间。
- 视觉核验发现部分底物浓度范围的图注与横坐标不一致：Figure S2b、S7b、S8e。暂不根据这些范围判断饱和程度或自动剔除记录；原始标签保持不变。

**处置：**初始速率和浓度归一化两个缺口取得实质进展。误差、浓度范围和统计独立性仍需处理，尚不能标记正式评价就绪。原始逐时间点数据未恢复，本轮不声称完成原始曲线复算。
